# Access request procedure

## When a request is needed

Employees must request access when a work application, shared folder, or team resource is not already available through their assigned role.

Access should be limited to the tasks the employee is expected to perform. A colleague's existing permission is not a reason to copy that permission without review.

## Information to include

Submit the request through the internal service portal.

Select the resource name, describe the business task that requires it, and state whether the access is temporary or ongoing.

Include the manager or resource owner who can confirm the work need.

Do not include passwords, authentication codes, or unrelated personal information in the ticket.

## Approval sequence

The manager confirms the business need first.

The resource owner then checks whether the requested level is appropriate for the resource.

Some systems require an additional data-owner or security review.

A ticket is not an approval by itself, and employees must wait until the portal shows that the request has been completed.

## Request tracking

The service portal assigns the synthetic request reference ARQ-2607 to the training example.

In real use, the requester should quote the reference generated for their own ticket.

The portal displays the current state, pending approver, and any question that requires a response.

Avoid opening duplicate tickets while an existing request is being reviewed.

## Changes and expiry

If the employee changes role, project, or team, the manager should review whether the access is still required.

Temporary permissions expire on the date recorded in the request.

A new task may require a new request rather than an informal extension.

## If access is denied

A denied request should include a reason or a next step where possible.

The employee may clarify the business need or ask the manager to review the decision.

Do not attempt to reach the resource through another employee's account, a shared password, or an unapproved copy of the data.
